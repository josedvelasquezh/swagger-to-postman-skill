# LinkedIn Announcement Draft

## Spanish

Publiqué **Swagger to Postman**, un skill abierto para ayudar a convertir especificaciones Swagger/OpenAPI en colecciones de Postman organizadas y revisables.

Antes de generar los archivos, el skill analiza la API, pregunta por las decisiones que faltan y presenta un árbol con operaciones y escenarios para aprobación. También distingue respuestas documentadas de solicitudes que realmente se pueden ejecutar, protege secretos y trata la especificación como entrada no confiable.

El proyecto es gratuito, público y está publicado bajo licencia MIT. Agradezco comentarios, casos de prueba y contribuciones.

GitHub: https://github.com/josedvelasquezh/swagger-to-postman-skill

## English

I published **Swagger to Postman**, an open Agent Skill that helps turn Swagger/OpenAPI specifications into organized, reviewable Postman collections.

Before creating files, it analyzes the API, asks about unresolved choices, and presents an operation-and-scenario tree for approval. It distinguishes documented responses from executable requests, protects secrets, and treats API specifications as untrusted input.

The project is free, public, and MIT-licensed. Feedback, test cases, and contributions are welcome.

GitHub: https://github.com/josedvelasquezh/swagger-to-postman-skill
