# Changelog

All notable user-facing changes are documented here.

## [0.2.0] - 2026-11-13

### Added

- Detailed Swagger/OpenAPI to Postman mapping rules.
- Security threat scenarios and manual release checklist.
- LinkedIn announcement drafts in Spanish and English.

### Changed

- External reference resolution now defaults to no automatic fetching when the agent cannot enforce network/path boundaries.
- Clarified collection examples, auth inheritance, parameter serialization, and script restrictions.

## [0.1.1] - 2026-11-13

### Changed

- Removed the Python validator so collection generation and review do not require a specific runtime.

## [0.1.0] - 2026-11-13

### Added

- Initial Agent Skill workflow, implementation plan, documentation, and examples.
